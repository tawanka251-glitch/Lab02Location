# PokéAR GO · AR ตามพิกัด (Location-based) 🎮

เกม AR สไตล์ Pokémon GO ที่ให้ผู้เล่นเดินถือโทรศัพท์มือถือออกตามหาและ "จับ" ภาพปริศนาทั้ง 3 ภาพ (จุด A, จุด B, จุด C) ในพิกัดสถานที่จริง โดยพัฒนาต่อยอดจาก A-Frame 1.6.0 + AR.js 3.4.8

---

## 🌟 ฟีเจอร์สไตล์ Pokémon GO ในโปรเจกต์นี้

1. **Nearby Radar (แถบเรดาร์ด้านล่าง):** แสดงการ์ดของภาพทั้ง 3 จุด พร้อมระยะทางแบบเรียลไทม์ และสถานะ (กำลังค้นหา / ใกล้มาก / อยู่ในระยะจับ / สะสมแล้ว)
2. **ระบบตรวจจับระยะ (Proximity Encounter):** เมื่อเดินเข้าใกล้เป้าหมายในระยะ **10 เมตร** ป้ายเตือนจะกระพริบพร้อมเสียงเตือน 
3. **ระบบจับภาพ (Catch & Collection):** ผู้เล่นสามารถแตะปุ่ม "จับภาพ! 🎯" หรือแตะรูปภาพ 3D ในกล้อง AR เพื่อเปิดการ์ดข้อมูลและกด "เก็บภาพเข้าสมุดสะสม" (มีเอฟเฟกต์เสียง 8-bit Pokéball Gotcha!)
4. **สมุดสะสมภาพ (Pokédex / Bag):** กดไอคอนกระเป๋า 🎒 ด้านบนเพื่อดูภาพทั้งหมดที่เก็บสะสมได้
5. **ปุ่ม "📍 เซ็ตจุดรอบตัวฉัน" (ฟีเจอร์เด็ดสำหรับเล่นได้ทุกที่):** เพียงแค่กดปุ่มนี้ ระบบจะดึงพิกัด GPS ปัจจุบันของผู้เล่น แล้ววางภาพทั้ง 3 จุดรอบตัวในระยะ 12–15 เมตรทันที ทำให้สามารถเล่นได้ทุกที่ (สนามหญ้า ลานกว้าง สวนสาธารณะ) โดยไม่ต้องแก้ไขโค้ดพิกัดด้วยตนเอง
6. **ฉลองชัยชนะ (Victory Celebration):** เมื่อตามหาและจับภาพครบทั้ง 3 จุด จะมีหน้าจอแสดงความยินดีพร้อมเอฟเฟกต์พลุ (Confetti) และเสียง Fanfare
7. **เข็มทิศนำทาง (Direction Guide):** มีลูกศรชี้บอกทิศทางไปยังเป้าหมายที่เลือก
8. **โหมดจำลอง (?sim):** สำหรับทดสอบบนคอมพิวเตอร์ มีปุ่ม D-Pad (⬆️ ⬇️ ⬅️ ➡️) ให้กดเดินจำลองได้ทันที

## 🚀 ขั้นตอนการนำขึ้น GitHub และเปิดเล่นบนมือถือ

### 1. บันทึกและส่งโค้ดขึ้น GitHub (Push to Git)
เปิด Terminal (หรือ Git Bash / PowerShell) ที่โฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
git add .
git commit -m "Update Pokemon GO AR hunting game"
git push origin main
```

*(หมายเหตุ: ลิงก์ Repository ของคุณคือ `https://github.com/tawanka251-glitch/Lab02Location`)*

---

### 2. เปิดใช้งาน GitHub Pages เพื่อรับลิงก์ HTTPS
> **สำคัญ:** มือถือจะยอมให้เปิดกล้องและ GPS ได้ก็ต่อเมื่อเว็บรันอยู่บน **HTTPS** เท่านั้น

1. เปิดเบราว์เซอร์ไปที่: [https://github.com/tawanka251-glitch/Lab02Location](https://github.com/tawanka251-glitch/Lab02Location)
2. คลิกแท็บ **Settings** (รูปเฟืองด้านบนขวา)
3. เมนูด้านซ้ายเลือก **Pages**
4. ตรงส่วน **Build and deployment**:
   - **Source:** เลือก `Deploy from a branch`
   - **Branch:** เลือก `main` และโฟลเดอร์ `/(root)`
   - คลิกปุ่ม **Save**
5. รอประมาณ 1–2 นาที GitHub จะสร้างลิงก์สำหรับเล่นเกมให้:
   👉 **`https://tawanka251-glitch.github.io/Lab02Location/`**

---

### 3. วิธีเปิดเล่นบนโทรศัพท์มือถือ

1. **เปิดด้วย QR Code จากคอมพิวเตอร์:**
   - เปิดลิงก์ `https://tawanka251-glitch.github.io/Lab02Location/` บน Google Chrome บนคอมพิวเตอร์
   - คลิกที่แถบที่อยู่ (URL Bar) -> คลิกไอคอน **แชร์** -> เลือก **"สร้าง QR Code" (Create QR Code)**
   - ใช้โทรศัพท์มือถือสแกน QR Code เพื่อเปิดเว็บ
2. **หรือพิมพ์/แชร์ลิงก์ส่งเข้ามือถือโดยตรง:**
   - ส่งลิงก์เข้าแอป LINE, แชท หรือเปิดใน Chrome / Safari
   - ⚠️ **ข้อควรระวัง:** ให้เปิดด้วย **Google Chrome (Android)** หรือ **Safari (iPhone)** โดยตรง อย่าเปิดค้างในเบราว์เซอร์ของแอป LINE/Facebook
3. **อนุญาตสิทธิ์:**
   - เมื่อเปิดเว็บ ให้กด **"อนุญาต" (Allow)** ทั้งสิทธิ์ **กล้อง (Camera)** และสิทธิ์ **ตำแหน่ง (Location / GPS)**
   - สำหรับ iPhone: หลังอนุญาต ให้แตะหน้าจอ 1 ครั้งเพื่อเปิดเซนเซอร์เข็มทิศ
4. **เริ่มเล่น:**
   - เดินไปในที่โล่งแจ้ง
   - กดปุ่ม **"📍 เซ็ตจุดรอบตัวฉัน"** บนแถบด้านบน เพื่อกระจายภาพทั้ง 3 ภาพไว้รอบตัวในระยะ 15 เมตร
   - เดินถือมือถือหมุนตามหาภาพ เมื่อเข้าใกล้ในระยะ 10 เมตร ให้แตะปุ่ม **"จับภาพ! 🎯"** หรือแตะที่ภาพในกล้อง AR ได้เลย!
