# AR ตามพิกัด (Location-based) · 0214381 Lab 3

Template สำหรับวางวัตถุ AR ไว้ ณ พิกัด GPS จริงด้วย A-Frame 1.6.0 + AR.js 3.4.8 (ชุดเดียวกับ Lab 1) เดินถือมือถือไปรอบ ๆ แล้วจะเห็นวัตถุอยู่ตามจุดที่กำหนด แถบด้านบนบอกพิกัดของเรา ความแม่นยำ GPS และระยะห่างจากแต่ละจุด

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | หน้าเว็บ AR และตำแหน่ง GPS |
| `assets/point-a.png` | ภาพหน้าจอที่แสดงตรงจุด A |
| `assets/point-b.png` | ภาพหน้าจอที่แสดงตรงจุด B |
| `assets/point-c.png` | ภาพหน้าจอที่แสดงตรงจุด C |

## ขั้นตอน (เหมือน Lab 1)

1. กด **Use this template → Create a new repository** ตั้งชื่อ `ar-location` เลือก **Public**
2. **Settings → Pages** เลือก Branch **main** และ **/ (root)** แล้วกด **Save**
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/ar-location/`

## เปิดบนมือถือด้วย QR Code

1. ทำขั้นตอน GitHub Pages ด้านบนให้เสร็จก่อน เพราะมือถือเปิดไฟล์ในคอมพิวเตอร์โดยตรงไม่ได้ และการใช้กล้อง/GPS ต้องเปิดผ่าน HTTPS
2. เปิดลิงก์ GitHub Pages บนคอมพิวเตอร์ด้วย Chrome
3. คลิกไอคอนแชร์ในแถบที่อยู่ แล้วเลือก **สร้าง QR Code** จากนั้นดาวน์โหลดหรือแสดง QR Code
4. ใช้กล้องมือถือสแกน QR Code แล้วแตะลิงก์ที่ปรากฏ อนุญาตการใช้กล้องและตำแหน่งเมื่อเบราว์เซอร์ถาม

ถ้าต้องการทดสอบโหมดจำลอง ให้สร้าง QR จากลิงก์ที่ลงท้ายด้วย `?sim` (เช่น `https://<ชื่อผู้ใช้>.github.io/ar-location/?sim`) ส่วนการใช้ GPS จริงให้สแกนลิงก์ปกติ

## สองโหมดของลิงก์เดียวกัน

| เปิดลิงก์แบบนี้ | ใช้เมื่อ |
| --- | --- |
| `https://<ชื่อผู้ใช้>.github.io/ar-location/?sim` | **โหมดจำลอง** ใช้ในห้องหรือบนคอมพิวเตอร์ ระบบจะสมมติว่าเรายืนห่างจากจุด A ไปทางทิศใต้ประมาณ 33 เมตร |
| `https://<ชื่อผู้ใช้>.github.io/ar-location/` | **โหมดจริง** ใช้นอกอาคาร ใช้ GPS ของมือถือ |

## แก้ผลงานของตัวเอง

1. หาพิกัดสถานที่: Google Maps บนมือถือ แตะค้างที่จุดที่ต้องการ พิกัดจะขึ้นในช่องค้นหา (เช่น `7.123456, 100.123456` ตัวแรกคือ latitude ตัวหลังคือ longitude) บนคอมพิวเตอร์ให้คลิกขวาที่แผนที่ แล้วคลิกพิกัดบรรทัดแรกเพื่อคัดลอก
2. พิกัด A/B/C ใน `index.html` เป็นค่าคงที่ จุด B/C เป็นตำแหน่งทดลองใกล้ A; เปลี่ยน latitude/longitude ของแต่ละจุดให้ตรงกับตำแหน่งที่ต้องการ
3. เปลี่ยนไฟล์ภาพในโฟลเดอร์ `assets` หากต้องการใช้ภาพอื่น โดยคงชื่อไฟล์เดิมไว้ หรือแก้ `src` ใน `index.html`
4. อัปโหลดทั้ง `index.html` และโฟลเดอร์ `assets` ไป GitHub แล้วกด **Commit changes** รอ 1–2 นาที และรีเฟรชบนมือถือ

## แก้ปัญหาเบื้องต้น

- **ขึ้นข้อความ GPS ใช้ไม่ได้:** ต้องเปิดเว็บผ่าน HTTPS (เช่น GitHub Pages) และอนุญาต Location ให้เบราว์เซอร์/เว็บไซต์ หากเคยกดปฏิเสธ ให้เปลี่ยนสิทธิ์ Location ของเว็บไซต์ในการตั้งค่าเบราว์เซอร์ แล้วโหลดหน้าใหม่
- **หาตำแหน่งไม่พบ / ใช้เวลานาน:** เปิด Location ของมือถือ ออกไปที่โล่ง และรอสักครู่ ในอาคาร GPS มักใช้ไม่ได้; ข้อความบนแถบด้านบนจะแจ้งสาเหตุที่เบราว์เซอร์รายงาน
- **ตำแหน่งแกว่ง:** พิกัดในโค้ดไม่ขยับ แต่ GPS/เข็มทิศมือถือมีความคลาดเคลื่อน จึงทำให้ภาพแกว่งบนหน้าจอได้ ค่า ±105 เมตรไม่แม่นพอจะแยกจุดที่ห่างกัน 5 เมตร ควรทดสอบกลางแจ้งและใช้พิกัดจากหมุดสถานที่จริง
- **iPhone:** หลังอนุญาตกล้องให้ **แตะหน้าจอ 1 ครั้ง** เพื่ออนุญาตเซนเซอร์ทิศทาง ถ้ายังไม่ได้ ไปที่ Settings → Safari → Motion & Orientation Access
- **วัตถุลอยไปมา / กระโดด:** เป็นธรรมชาติของ GPS มือถือ (คลาดเคลื่อน 5–20 เมตร) ดูค่า "ความแม่นยำ" บนแถบด้านบน ยืนนิ่ง ๆ ในที่โล่งสักครู่
- **ทิศผิด:** เข็มทิศมือถืออาจเพี้ยน หมุนมือถือเป็นรูปเลข 8 กลางอากาศ 2–3 รอบ
- **ไม่เห็นวัตถุทั้งที่ระยะถูก:** ลองหันรอบตัวช้า ๆ หรือขยาย `scale` ให้ใหญ่ขึ้น วัตถุที่ห่างเกินประมาณ 100 เมตรจะเล็กมาก
- **กล้องไม่เปิด:** เปิดใน Chrome หรือ Safari โดยตรง ไม่ใช่เบราว์เซอร์ในแอป LINE/Facebook
