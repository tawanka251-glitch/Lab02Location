# AR ตามพิกัด (Location-based) · 0214381 Lab 3

Template สำหรับวางวัตถุ AR ไว้ ณ พิกัด GPS จริงด้วย A-Frame 1.6.0 + AR.js 3.4.8 (ชุดเดียวกับ Lab 1) เดินถือมือถือไปรอบ ๆ แล้วจะเห็นภาพทั้ง 3 รูปอยู่ตามจุดที่กำหนดในระยะไม่เกิน 5 เมตร แถบด้านบนบอกพิกัดของเรา ความแม่นยำ GPS และระยะห่างจากแต่ละจุด

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | หน้าเว็บ AR และตำแหน่ง GPS |
| `assets/point-a.png` | ภาพหน้าจอที่แสดงตรงจุด A |
| `assets/point-b.png` | ภาพหน้าจอที่แสดงตรงจุด B |
| `assets/point-c.png` | ภาพหน้าจอที่แสดงตรงจุด C |

## การทำงานของระบบ (ระยะไม่เกิน 5 เมตร)

- **เมื่อเปิดบนมือถือ (GPS จริง):** ทันทีที่ระบบจับสัญญาณ GPS ได้ จะปักหมุดภาพทั้ง 3 จุดให้อยู่รอบตัวผู้ใช้ในระยะ **3 – 4.5 เมตร (ไม่เกิน 5 เมตร)** ทันที ทำให้สามารถเดินหาภาพได้ทุกที่กลางแจ้ง
- **ปุ่มปักหมุดรอบตัว:** มีปุ่ม `📍 ปักหมุด 3 รูปให้อยู่รอบตัวฉัน` บนแถบ HUD ให้กดรีเซ็ตตำแหน่งภาพให้อยู่รอบตัวได้ตลอดเวลา
- **โหมดจำลอง (`?sim`):** เมื่อเปิดลิงก์พร้อม `?sim` ระบบจะจำลองให้ผู้ใช้ยืนห่างจากจุด A เพียงประมาณ 3.8 เมตร (ไม่เกิน 5 เมตร)

## ขั้นตอนการนำขึ้น GitHub Pages

1. ส่งโค้ดขึ้น GitHub:
   ```bash
   git add .
   git commit -m "Update AR location targets within 5 meters"
   git push origin main
   ```
2. ไปที่ GitHub Repository: [https://github.com/tawanka251-glitch/Lab02Location](https://github.com/tawanka251-glitch/Lab02Location)
3. เข้า **Settings → Pages** เลือก Branch **main** และ **/ (root)** แล้วกด **Save**
4. ลิงก์สำหรับเปิดบนมือถือ:
   👉 `https://tawanka251-glitch.github.io/Lab02Location/`

## เปิดบนมือถือด้วย QR Code

1. เปิดลิงก์ GitHub Pages ด้านบนด้วย Chrome บนคอมพิวเตอร์
2. คลิกไอคอนแชร์ในแถบที่อยู่ แล้วเลือก **สร้าง QR Code**
3. ใช้กล้องมือถือสแกน QR Code แล้วแตะลิงก์ที่ปรากฏ อนุญาตการใช้กล้องและตำแหน่งเมื่อเบราว์เซอร์ถาม
4. เดินถือมือถือหมุนดูรอบตัวในระยะไม่เกิน 5 เมตร จะเห็นภาพทั้ง 3 ภาพปรากฏขึ้นในกล้อง AR
